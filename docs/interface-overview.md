# Афина — описание функционала интерфейса

Документ описывает, что делает каждый раздел и экран прототипа, и какие действия доступны пользователю. Прототип — single-page приложение: все экраны переключаются через единый стейт (`view`), отдельных URL-маршрутов нет.

---

## Оболочка приложения (shell)

Постоянный каркас вокруг всех экранов.

- **Левый сайдбар** (узкий, ~120px): логотип Афина, навигация — «Последнее», «Сигналы», «Кампании», «Статистика», внизу — меню пользователя (аватар, баланс, выход). Активный раздел подсвечен, на «Сигналах» появляется бейдж при новых готовых сигналах.
- **«Последнее»** — флайаут быстрого доступа: поиск + последние сигналы и кампании со статус-точками. Открытие элемента ведёт на его детальный экран. Навигация стрелками, Enter / Escape.
- **Промпт-бар (маскот «Афина ИИ»)** — нижняя панель: иконка маскота, поле ввода, контекстные подсказки-чипы. Появляется в момент AI-помощи. Подсказки только подставляют текст в поле — действие выполняется по сабмиту.
- **Чат-дровер** — полноразмерная боковая панель с историей диалога с ассистентом. Промпт-бар при открытом дровере скрывается.

---

## 1. Велком-экран

Первый экран. Объясняет продукт и ведёт в онбординг или к подбору сигналов.

- Заголовок-приветствие и краткое описание логики продукта: выбрать сигнал по сценарию → запустить кампанию → следить за результатом в статистике.
- Карточки шагов онбординга (визуальная схема воркфлоу).
- CTA-блок с двумя состояниями:
  - **до анкеты:** «Расскажите о вашей задаче — подберём сценарии» → кнопка ведёт в анкету;
  - **после анкеты:** «Подобрали N сценариев под ваш бизнес» → кнопка запускает подбор сигналов.

**Действия:** начать онбординг (анкета) или сразу перейти к созданию сигнала.

---

## 2. Анкета / регистрация (survey)

Полноэкранный онбординг: собирает данные о компании, чтобы курировать рекомендации сценариев и интересов. Сайдбар скрыт.

Проходит фазы:
1. **Форма** — поле «сайт компании» с валидацией. По сайту система «понимает», чем занимается бизнес.
2. **Обработка** — анимация анализа сайта (магия под капотом).
3. **Интересы** — экран выбора подобранных интересов под нишу.
4. **Сценарии** — экран выбора подобранных сценариев (визуальные карточки).

**Действия:** ввести сайт, выбрать направление и интересы, подтвердить. По завершении — возврат на велком с подсвеченным «Найти сигналы». Escape — выход на велком.

---

## 3. Мастер создания сигнала (wizard, 8 шагов)

Главный сценарий продукта — пошаговая настройка сигнала (целевой аудитории). Доступен из велкома, кабинета сигналов или при возобновлении незавершённого сигнала.

| Шаг | Назначение | Что делает пользователь |
|-----|------------|--------------------------|
| **1. Сценарий** | Каталог готовых сценариев | Поиск + фильтр по категориям; выбор курированного или произвольного сценария. Если сценарий выбран заранее — шаг пропускается |
| **2. Интересы и триггеры** | Уточнение аудитории | Выбор направления и интересов, сборка триггер-выражений (включение/исключение доменов), предпросмотр подходящих доменов. Есть кнопка «перемешать» (re-roll подсказок) |
| **3. Качество аудитории (сегменты)** | Компромисс цена/охват | Выбор сегментов качества: max / high / mid / low с ценой и оценкой объёма |
| **4. Загрузка базы (опционально)** | Своя база ID | Drag-drop CSV/TXT, авто-подсчёт строк; можно пропустить |
| **5. Бюджет** | Объём поиска | Рекомендуемый или свой бюджет; оценка «примерно N сигналов» и стоимости. Чип «Как выбрать бюджет?» открывает ответ ассистента |
| **6. Проверка и запуск** | Сводка параметров | Просмотр всех параметров, кнопка запуска. Предупреждение при нехватке баланса |
| **7. Обработка** | Поиск сигналов | Анимация ожидания; авто-переход на шаг 8 при готовности |
| **8. Результат** | Готовые сигналы | Итоговый объём + разбивка по сегментам; запуск кампании / создание ещё одного / переход в кабинет |

**Логика оплаты:** при достаточном балансе сигнал сразу уходит в обработку; при нехватке — модалка пополнения. Отмена оплаты оставляет сигнал в статусе «ожидание платежа» — его можно возобновить позже из кабинета.

## 4. Кабинет сигналов

Список всех созданных сигналов с управлением.

- Заголовок «Сигналы» + меню «Создать сигнал» / «Загрузить».
- Пустое состояние с призывом создать первый сигнал.
- Список карточек сигналов (одна колонка, новые сверху). Карточка показывает: тип и имя сигнала, объём, разбивку по сегментам, дату, статус-бейдж (обработка / ожидание платежа / ошибка / истекло).

**Действия по карточке:** открыть детальный экран (для готовых), запустить кампанию, открыть и редактировать (для неоплаченных), скачать CSV, удалить (с подтверждением), пополнить баланс.

---

## 5. Детальный экран сигнала

Карточка готового сигнала с метаданными и переходом к кампании.

- Шапка: имя (редактируемое), статус, дата получения.
- Разделы: сценарий, интересы и триггеры, сегменты качества (с объёмами и ценами), загруженный файл, бюджет.
- **Действия:** запустить кампанию по сигналу, скачать CSV, переименовать, вернуться в кабинет.

---

## 6. Создание кампании

### 6.1 Выбор типа кампании
Промежуточный экран после сигнала — выбор шаблона/типа кампании (канал) карточками.

### 6.2 Конструктор воркфлоу (визуальный редактор)
Граф из узлов и связей, описывающий логику кампании.

- **Типы узлов:** Старт (сигнал, авто), действия (Email, SMS, и т.п.), Задержка, Условие (ветвление), Успех (терминальный, авто).
- **Действия:** перетаскивание узлов, соединение/удаление связей, редактирование свойств узла. Узлы с незавершённой настройкой помечаются индикатором.
- **Валидация перед запуском:** сигнал не привязан / есть неготовые узлы / нет пути к узлу «Успех».
- Кнопка запуска прогоняет валидацию и ведёт на оплату.

### 6.3 Экран оплаты кампании
Подтверждение бюджета перед запуском: стоимость запуска, текущий баланс, пополнение, кнопка запуска (активна при достаточном балансе). Успех → кампания становится активной.

---

## 7. Детальный экран кампании

Метаданные, статус и управление кампанией.

- Шапка: имя (редактируемое), статус-бейдж (черновик / активна / остановлена / завершена) и дата соответствующего события.
- Мини-превью воркфлоу, список каналов, привязанный сигнал.
- Статистика (для активных/завершённых): охват, конверсия, прибыль.
- **Действия:** открыть/редактировать воркфлоу, запустить (для черновика), остановить (для активной), удалить, перейти в статистику по кампании.

---

## 8. Кабинет кампаний

Список всех кампаний с фильтрацией и сортировкой.

- Заголовок «Кампании» + меню создания.
- Пустое состояние с переходом в «Сигналы» (кампания создаётся от сигнала).
- Фильтр-чипы по статусу; сортировка: по дате / по прибыли / по конверсии.
- Карточки кампаний: имя, статус, привязанный сигнал, дата, метрики (охват, конверсия, прибыль).

**Действия:** открыть кампанию, создать новую (требует сигнал).

---

## 9. Статистика

Сводный отчёт с группировками, детализацией и экспортом.

- **Период:** пресеты (сегодня / неделя / месяц) или свой диапазон.
- **Вид отчёта (группировка):** по кампаниям / сигналам / каналам / датам.
- **Фильтры** по сущностям; метрики: охват, конверсия, стоимость, прибыль.
- **Детализация:** клик по строке открывает поповер с разбивкой.
- **Действия:** экспорт CSV, сохранение текущей конфигурации как шаблона.

## 10. Настройки аккаунта

Данные аккаунта, которые питают AI-логику. Вертикальные блоки:

| Блок | Назначение |
|------|------------|
| **Сайт** | Основной домен для анализа |
| **Бизнес** | Отрасль и описание — курируют интересы и сценарии |
| **Регионы** | Гео-таргетинг для подбора сигналов |
| **Резюме** | AI-сгенерированное резюме профиля (только чтение) |
| **Интересы** | Кураторские интересы для мастера |
| **Голос бренда** | Тон для генерации текстов |
| **Глобальные исключения доменов** | Домены, которые никогда не используются ни в одном триггере |

Каждый блок: заголовок + описание + поля/чипы, сохранение по изменению.

## Сквозные механизмы

- **Маскот / AI-ассистент** — появляется функционально в момент помощи (промпт-бар, AI-fill интересов, подсказка по бюджету), не как декор. Контекстные подсказки зависят от текущего шага/экрана.
- **Баланс и оплата** — единый кошелёк; модалка пополнения возникает в мастере сигнала и при запуске кампании.
- **Статусы сигналов:** черновик → ожидание платежа → обработка → готово; также ошибка / истекло.
- **Статусы кампаний:** черновик → активна → остановлена → завершена.
- **Локаль:** русский, рубли (₽), даты ДД.ММ.ГГГГ, корректная плюрализация и группировка чисел.

## Ключевые пользовательские пути

1. **Онбординг:** велком → анкета (сайт → анализ → интересы → сценарии) → подбор сигналов → мастер → оплата → готовый сигнал.
2. **Создание сигнала:** кабинет сигналов → мастер (8 шагов) → запуск → обработка → результат.
3. **Создание кампании:** от сигнала → выбор типа → конструктор воркфлоу → валидация → оплата → активная кампания.
4. **Аналитика:** статистика → период + группировка + фильтры → детализация → экспорт.
