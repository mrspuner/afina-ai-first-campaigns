# Спека — Группа C: граф как путь кампании и кампания без стадий (встреча 2026-06-23)

Третий из трёх циклов разбиения правок встречи 2026-06-23 (A → B → **C**). Группа A влита в `integration`; Группа B готова в ветке `feature/group-b` (модель `Campaign.files[]`).
**Группа C** — блоки **8 и 9**: граф читается как путь кампании (Файл → Скоринг → Сигнал → Коммуникация) с правкой скоринга через дровер и показом баз на графе; и «открытая» кампания без стадийного индикатора, у потока — сигнал в реальном времени.

Источник: мастер-спека `2026-06-23-meeting-1423-edits-spec.md` (блоки 8, 9) — локальный файл, на диске не сохранён; содержание восстановлено из разбора прошлой сессии и **сверено с кодом `integration`** (AS-IS ниже — фактические file:line).

**Не входит в Группу C (отдельный трек):** Блок 7 — перестройка модели полей нод (Select-везде + ИИ-пункт, каналы → «Шаблон», таймпикер/duration/справочник событий, удаление Витрины/Лендинга). Блок 8 строится на **текущей** модели нод (`scoring` уже есть через `withScoring`), без перестройки Блока 7. См. `docs/edits/2026-06-24-block7-node-fields-decisions.md`.

**Зависимости исполнения.** Блок 8 опирается на `Campaign.files[]` (Группа B) — «показать базы» и «добавить файл» без него не компилируются. Поэтому Группа C исполняется **после слияния B в `integration`**. Блок 9 почти независим (трогает `campaign-screen` / `signal-progress` / `phase`), может идти параллельно с B, но в одном цикле с Блоком 8.

Все строки интерфейса — на русском.

## Блок 8. Граф как путь кампании: Файл → Скоринг → Сигнал → Коммуникация

**AS IS.**
- Шаблон графа (`src/state/workflow-templates.ts`): входная нода — id `"signal"`, тип **`"source"`**, лейбл **«Сигнал»**, несёт `SignalParams` (`fileName` захардкожен на шаблон, `count`, `segments`). Это единственная нода-источник.
- `withScoring()` (`workflow-templates.ts:273-298`) вставляет ноду `scoring` между источником и первой downstream-нодой для `new`/`stream` (для `own` — нет). Применяется в `createTemplate(...)` (`~:512-532`): `sourceType === "own" ? base : withScoring(base)`.
- Текущий видимый путь: **Сигнал(source) → Скоринг → [каналы] → Успех/Конец**.
- Нода `scoring`: лейбл «Скоринг», сублейбл «Качество базы», иконка `Gauge`, **без params** (`nodeNeedsAttention` = false, не блокирует запуск). `node-visuals.ts:30-80` — стили/иконки; скоринг временно переиспользует палитру `source` (`node-visuals.ts:33-36`).
- **Интересы/триггеры НЕ живут на ноде графа** — они в `StepData` (визард), на графе не редактируются.
- `workflow-view.tsx` (`WorkflowView`, props `:265-283`) рендерит граф через `<WorkflowGraph>`; **не читает** `Campaign.file/files`; нет действий «показать базы» / «добавить файл». `campaignId` — только ключ durable-кэша.
- Типы нод — `WorkflowNodeType` (`src/types/workflow.ts:3-28`): есть `source`, `scoring`, `signal`, каналы и пр.
- На `integration` у кампании пока `file?` (один); `Campaign.files[]` приходит из Группы B.

**TO BE.**
- Граф читается слева-направо как **путь кампании: Файл → Скоринг → Сигнал → Коммуникация** — вместо одиночной входной ноды «Сигнал». Конкретно:
  - Входная нода → **«Файл»** (тип `source`): показывает загруженные базы (имена + размеры из `Campaign.files`/`StepData.files`), несёт действие **«Добавить файл»**.
  - **«Скоринг»** — остаётся (для `new`/`stream`); теперь несёт **интересы/триггеры** как редактируемые params, правка через **боковой дровер** (тот же механизм правки params ноды).
  - **«Сигнал»** — нода-результат скоринга (готовая аудитория) перед коммуникацией. Для `own` (базы предскорены) путь схлопывается до **Файл → Сигнал → Коммуникация** (скоринга нет, как и сейчас).
  - **«Коммуникация»** — существующие ноды каналов (без изменений в Группе C).
- **Показ баз на графе:** нода «Файл» отображает список загруженных баз (`campaignBaseRows` / имена). Если баз нет — плейсхолдер.
- **«Добавить файл» на графе:** действие на ноде «Файл» (или на пане рядом) — открывает загрузку базы, добавляет в `Campaign.files` (reuse `DropZone` из Группы B). Прототип: достаточно положить файл в состояние кампании; без серверной загрузки.
- **Скоринг через дровер:** при выборе ноды «Скоринг» боковой дровер показывает интересы/триггеры кампании, редактируемые. Источник значений — `campaign.interests` / триггеры; на прототипе — отображение и базовая правка (полная AI-правка полей — Блок 7, вне скоупа).

> **Развилки (решить при реализации, дефолт — рекомендованный):**
> 1. **«Файл» и «Сигнал» — две ноды или относировать одну?** Рекоменд.: входная `source`-нода → лейбл «Файл» (показ баз + «добавить»), плюс отдельная нода «Сигнал» (тип `signal`) после скоринга как результат. Минимально — переименовать входную в «Файл» и добавить «Сигнал» после `scoring` в шаблоне (`withScoring`/`createTemplate`).
> 2. **Где живут интересы/триггеры на ноде «Скоринг»** — новые поля `ScoringParams` в `node-params` (`{ kind: "scoring", interests, triggers }`) или ссылка на `campaign.interests`. Рекоменд.: лёгкий `ScoringParams` со списками, заполняется из визарда при создании кампании.

**Тексты.**
- Лейбл входной ноды: **«Файл»** (сублейбл — имя/число баз, например «2 базы · ~14 000 строк»).
- Нода-результат: **«Сигнал»** (сублейбл — тип сигнала/сценарий).
- Действие на ноде «Файл»: **«Добавить файл»**.
- Дровер скоринга: заголовок **«Скоринг»**, секции **«Интересы»**, **«Триггеры»**.

**Маппинг.**
- `src/state/workflow-templates.ts`: входная нода — лейбл «Файл»; `withScoring`/`createTemplate` — добавить ноду «Сигнал» (`signal`) после `scoring` (для `new`/`stream`) и Файл→Сигнал для `own`; ноде `scoring` дать `ScoringParams` (интересы/триггеры).
- `src/types/workflow.ts` (где `SignalParams` и union params): добавить `ScoringParams { kind: "scoring"; interests: string[]; triggers: string[] }`.
- `src/sections/campaigns/node-visuals.ts`: иконка/палитра для «Файл» (Database) и «Сигнал» (SignalLow) — уже есть; убедиться, что лейблы консистентны.

- `src/state/app-state.ts`: экшен(ы) добавления базы в `Campaign.files` с графа (если ещё нет) — переиспользовать/добавить.

**Критерии приёмки.**
- Граф кампании читается как **Файл → Скоринг → Сигнал → Коммуникация** (для `own` — Файл → Сигнал → Коммуникация).
- Нода «Файл» показывает загруженные базы; есть действие «Добавить файл», добавляющее базу в кампанию.

- Скоринг по-прежнему не блокирует запуск (param-less-инвариант сохранён или интересы/триггеры опциональны).
- `workflow-templates.test.ts` и затронутые тесты зелёные; tsc без новых ошибок.

## Блок 9. Открытая кампания без стадий; поток — сигнал в реальном времени

"scoring"` (`:44`).
- Модель `phase?: "scoring" | "communicating"` (`app-state.ts:69`):

**TO BE.**
