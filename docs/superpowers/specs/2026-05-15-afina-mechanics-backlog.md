# Afina — бэклог реализации механик (нарезка ~30 мин)

> Источник: `./spec.md` (спецификация поведения шести механик)

## Как устроена нарезка

- Каждый чанк ≈ **30 минут** и заканчивается **видимым чекпоинтом** — конкретным
  экраном или поведением, которое открываешь на `localhost:3000` и проверяешь, не
  дожидаясь готовности всей механики.
- Чанки внутри механики упорядочены лесенкой — каждый следующий стоит на предыдущем.
- Карточка чанка: **Делаем / Файлы / ✅ Чекпоинт**. Чекпоинт — это и есть критерий «готово».
- Дев-сервер не останавливаем между чанками — результат смотрится сразу.

## Порядок выполнения

- **Можно брать сейчас:** M2, M3, M4 — не зависят от промпт-бара.
- **После раскатки промпт-бара на все разделы:** M5, затем M1 (почти весь покрыт M5)
  и M6.
- Рекомендованный поток: **M2 → M3 → M4 → M5 → M1 → M6**.
- Перед кодом — git-воркстри off ветки с актуальной работой (AGENTS.md). Каждый чанк
  заканчивается коммитом.
