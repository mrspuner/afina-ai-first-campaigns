## B. Шаг «Бюджет» (#3, #4, #5)
Файл: `src/sections/campaigns/wizard/steps/step-budget.tsx`. После batch-2 шаг считает по графу (`graphCostFor` → `CampaignCost { total, repeat, hasDynamic, lines:{channel,label,unit,reach,sum}[] }`).

- **#3 — «~N контактов» под «Сигналы».** Сейчас `contactLabel` (`~N контактов`) рендерится справа в строке (между лейблом и суммой). Перенести его ПОД строку «Сигналы» (отдельной muted-строкой, как канал-лист под «Коммуникацией»).
- **#4 — каждый канал отдельной строкой со своим бюджетом.** Сейчас одна строка «Каналы: SMS, Звонок». Заменить на список: каждый используемый канал — отдельная muted-строка с его бюджетом, из `cost.lines` (`{CHANNEL_LABEL[line.channel]} · {line.label}` … `{formatRub(line.sum)}`). Если граф-cost недоступен (нет сценария) — фоллбэк на простой список каналов из `data.channels` без сумм.
- **#5 — буфер с суммой.** Строка «Повторные коммуникации (+30% буфер)» — дописать сумму буфера (`cost.repeat`) справа: «Повторные коммуникации (+30% буфер) … {formatRub(cost.repeat)}». Показывать, когда `cost.hasDynamic`/`cost.repeat > 0`.

> #4/#5 читают тот же `cost`-объект, что уже в scope после batch-2. Не меняем модель стоимости.

## C. Экран оплаты (#8, #9)
Файл: `src/sections/campaigns/campaign-payment-screen.tsx`.

- **#9 — перенести «Из чего складывается» в «Платежи» под «Коммуникацию».** Сейчас два отдельных card-блока: «Из чего складывается стоимость» (`:280-317`, `cost.lines` + буфер) и «Платежи» (`:319-353`, Скоринг/Коммуникация/дневной). Перенести содержимое «Из чего складывается» (список строк) ВНУТРЬ «Платежи», сразу ПОД строку «Коммуникация» (как разворачивающая детализация). Один card-блок «Платежи». Сохранить guard-условия.
- **#8 — «Скоринг (сигналы)» помечать «уже оплачено».** В новом потоке (batch-2 G) сбор сигналов/скоринг происходит ДО экрана оплаты; на оплате платят за коммуникацию. Поэтому строку «Скоринг (сигналы)» показывать с пометкой **«уже оплачено»** (вместо/рядом с суммой) для `new`/`stream` (где скоринг был); для `own` остаётся «бесплатно». Конкретно: если у кампании уже есть собранный артефакт (скоринг прошёл) или sourceType≠own — выводить «уже оплачено»; own — «бесплатно».
